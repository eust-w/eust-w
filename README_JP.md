実世界の入力を、検証しやすいソフトウェアにつなげることに取り組んでいます。対象はカメラ幾何、データセット、ワールド記述、実行環境の接続、研究ワークスペースです。

<a id="projects"></a>
## 主な公開プロジェクト

| プロジェクト | 主な内容 |
| :--- | :--- |
| **[agentic-embedded-lab](https://github.com/eust-w/agentic-embedded-lab)** | エージェントを用いた組み込み実験、シミュレーション接続、検証記録。 |
| **[amd-bigym-3dgs-rocm](https://github.com/eust-w/amd-bigym-3dgs-rocm)** | AMD ROCm による 3DGS 再構成と BiGym 評価ワークフロー。 |
| **[WorldSpec](https://github.com/eust-w/WorldSpec)** | ワールドのスキーマ、検証、来歴管理、シミュレーターへの出力契約。 |
| **[robodata](https://github.com/eust-w/robodata)** | ロボットデータセットの変換・確認・品質分析。現在はアルファ版。 |
| **[Real2Motrix](https://github.com/eust-w/Real2Motrix)** | ローカルのデータ取得とメッシュ処理から MJCF / URDF シーンを出力。 |
| **[superscience](https://github.com/eust-w/superscience)** | ツール、Notebook、来歴管理を備えたローカル科学研究 AI ワークベンチ。 |
