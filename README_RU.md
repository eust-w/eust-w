## Избранные публичные проекты

| Проект | Что изучить |
| :--- | :--- |
| **[agentic-embedded-lab](https://github.com/eust-w/agentic-embedded-lab)** | Эксперименты со встраиваемыми системами, адаптеры симуляции и результаты проверок для ИИ-агентов. |
| **[amd-bigym-3dgs-rocm](https://github.com/eust-w/amd-bigym-3dgs-rocm)** | Реконструкция 3DGS на AMD ROCm и процессы оценки в BiGym. |
| **[WorldSpec](https://github.com/eust-w/WorldSpec)** | Схемы миров, валидация, происхождение данных и контракты экспорта в симуляторы. |
| **[robodata](https://github.com/eust-w/robodata)** | Конвертация, проверка и анализ качества робототехнических датасетов — альфа-версия. |
| **[Real2Motrix](https://github.com/eust-w/Real2Motrix)** | Локальный сбор данных и обработка сеток с экспортом сцен MJCF / URDF. |
| **[superscience](https://github.com/eust-w/superscience)** | Локальная научная ИИ-среда с инструментами, ноутбуками и учётом происхождения результатов. |

## Как связаны проекты

<img src="assets/project-map.svg" alt="Conceptual map of camera geometry, capture, robot data, world schemas, simulation, agents and research tools" width="100%" />

Концептуальная схема взаимодополняющих проектов. Интеграции, требования и результаты проверок описаны в каждом репозитории.

Для меня важны воспроизводимые примеры, явные интерфейсы и доказательства, позволяющие оценивать результаты.
